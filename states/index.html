Unclaimed retirement money by state

When a retirement account goes dormant, the money is often turned over to the state — and each state runs its own program with its own search site. Start with every state you have lived or worked in.

You can claim your property yourself, for free. Your state does not charge you to file a claim for your own property, and every registry we reference is free to search. ReclaimWealth charges only for optional help doing the legwork.
